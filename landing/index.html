What it does

A complete trading system you host yourself — not a service that touches your money.

📊

Live dashboard

Equity, per-pair P&L, positions with liquidation prices, and charts — updating in real time, in your timezone.

🧠

Strategy library

Confluence, EMA/SMA crossover, MACD, RSI, Bollinger, Donchian — switch and tune them live.

🛡️

Real risk controls

Leverage-aware sizing, stop-loss, take-profit, a liquidation backstop, and a daily-loss kill switch.

🔬

Honest backtester

Replays real candles through the live engine, net of fees, slippage and real funding — with walk-forward validation.

⚡

Live WebSocket feed

Real-time mark prices so stop-loss and liquidation checks react in ~1s, not at the next poll.

🔒

Install in one command

On any Linux box with Docker:

git clone https://github.com/BetterCallDzuks/crypto-bot.git
cd crypto-bot
cp .env.example .env        # add your Binance keys + a DASHBOARD_PASSWORD
touch config.local.yaml
docker compose up -d        # dashboard on http://127.0.0.1:4000

It runs in safe paper mode by default — no keys needed to try it. See the README and DEPLOY.md for going live and reaching the dashboard remotely (Tailscale, SSH tunnel, HTTPS).

Before you use it

This is not a money printer, and it is not financial advice. Trading leveraged futures can liquidate your position and lose your capital fast. Most strategies lose after fees and funding — the backtester exists to show you that before you risk anything. Paper-trade, then testnet, then start small.
